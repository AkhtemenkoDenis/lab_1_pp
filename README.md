# Веб-сайт, який присвячений грі "Вгадай число"

Ця гра була зроблена для лабораторної роботи з дисципліни "Веб-технології та Веб-дизайн", але за власною ініціативою було вдосконалено.

**Виконав**: Ахтеменко Денис

**Група**: АІ-224

**Тестування проекту**:
- Якщо ви бажаєте протестувати роботу програми, буде достатньо запустити проект, наприклад у Actions. Після цього можна перевіряти виконання коду вводивши цифри

- Або відкрити файл **index.html**, але перед запуском програми перевірити положення всіх необхідних файлів, вони повинні бути всі в одній папці.
